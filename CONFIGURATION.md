# Configuration and controls
Portable defaults live in `include/ngba/settings.hpp` and `include/ngba/controls.hpp`.
Default frontend-neutral key codes: A/B 0x200/0x201; L/R 0x202/0x203; Start/Select 0x204/0x205; D-pad 0x206–0x209. Remapping is supported in the model. Turbo fields exist, but timing/hold semantics need the platform input loop. Planned profiles: Nokia numeric keypad, QWERTY, camera/media keys, touch overlay, Bluetooth HID.
